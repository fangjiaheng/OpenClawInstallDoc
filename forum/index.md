## 常见问题

### 安装失败怎么办？

1. 检查网络连接
2. 尝试使用国内镜像源
3. 查看 [安装文档](/install/)
4. 在 GitHub 提交 Issue

### 如何获取 API 密钥？

访问 [Anthropic 官网](https://console.anthropic.com) 注册并获取 API 密钥。
